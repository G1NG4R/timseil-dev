1cDesign notes
/WORK
▸ Kein längeres SYS.02: jede Zeile trägt eine Betriebszahl, und welche, hängt vom Status ab — Uptime bei LIVE, letzter Commit bei BUILD, Spec-Zustand bei QUEUED
▸ Zwei Filterreihen, beide live: Status und Stack kombinieren sich, Zähler läuft mit, leere Kombination bietet Reset
▸ Brief-Punkt eingelöst: die monochrom-cyan Vorschau sitzt in einer reservierten Spalte bei 28 % und geht beim Hover auf 100 % — Enthüllung ohne Layout-Sprung
▸ Brief-Punkt eingelöst: ENTRIES IN THE LOG verbindet jedes System mit den Posts, die darüber geschrieben wurden
▸ Ein Alert-Moment: die Marke YOU ARE HERE auf Zeile 02
▸ Die Legende unten definiert LIVE, BUILD, QUEUED — Statuswörter sind nur so viel wert wie ihre Definition
▸ Mobile: Vorschau steht dauerhaft bei 88×66 statt auf Hover, Filter scrollen horizontal
▸ Alle Zahlen in [Klammern] kommen später aus /api/systems
