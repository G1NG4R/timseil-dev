SYS.05.03 HOW I WORK
01
Read the source before the docs

Documentation tells you the intent. The code tells you the behaviour. When the two disagree, production follows the code.

02
Ship it where it can break

A project on a laptop teaches you syntax. A project on a public address teaches you timeouts, certificates, backups, and your own blind spots.

03
Measure before you claim

Every number on this site has something producing it. If I cannot point at the source, the number does not go up.

04
Write the incident down

The outage is not the interesting part. The cause, the fix, and the thing I would set up differently next time are what carry over.

▸ Vier Prinzipien, keine Werte-Wolke. Jedes ist überprüfbar an dem, was die anderen Seiten zeigen
▸ Genau ein menschlicher Moment (SYS.05.04), bewusst kurz gehalten
▸ Headline dekodiert beim Laden, Puls und Sweep laufen langsam; prefers-reduced-motion stellt alles still
