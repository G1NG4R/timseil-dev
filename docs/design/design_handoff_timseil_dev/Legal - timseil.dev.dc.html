07.01Who is responsible

Tim Seil, [ADRESSE], Luxembourg — reachable at contact@timseil.dev. There is no data protection officer, because the scale of processing here does not require one.

07.02Server logs

Every request to this server is written to a log file, the same way every web server on the internet does it. That record is what makes it possible to see that the site is up, to find out why a page returned an error, and to notice when someone is probing for a way in.

FIELDWHY IT IS KEPTRETENTION
IP addressAbuse and rate limiting14 DAYS
TimestampOrdering, incident review14 DAYS
Method and pathWhich route was hit14 DAYS
Status code and sizeError detection14 DAYS
User agentRendering and bot filtering14 DAYS
ReferrerWhere a link came from14 DAYS

Legal basis: legitimate interest in operating and securing the service, Art. 6(1)(f) GDPR. Logs are rotated automatically and are not combined with anything else. Nobody but me reads them.

07.03Visitor counting

I count page views with [ANALYTICS TOOL], which runs on the same server as the rest of the site. It sets no cookie, assigns no identifier, and stores no profile. What it produces is a daily count per page and a list of referring domains.

The counter sets nothing on your device, and no individual can be singled out from the result — see 07.04 for the two entries the site does keep locally. There is no consent banner. A banner would be a worse trade for you than the thing it asks about.

07.04What is stored on your device

Two entries, both in local storage, both written only when you do something. No cookie, no identifier, and neither is ever sent back to the server — I cannot read them.

KEYWHAT IT HOLDSWHEN IT IS WRITTEN
ts.themeWhich of the seven colour schemes you pickedOn clicking a swatch
ts404.bestYour best score in the game on the 404 pageOn playing it
ts.langYour language choice — only if you pick one. The URL decides which language is shown; this entry only highlights it in the switcher.

Clearing your browser storage removes all three. Without them the site still works: it then follows your system setting for light or dark, and the game starts at zero.

07.05What never leaves this server
01Fonts. Served from this domain. Your browser makes no request to a font provider.
02The contribution graph. Fetched server-side from the GitHub API and cached here. Your browser never talks to GitHub.
03No embeds. No third-party video, no comment widget, no social buttons, no tag manager.
04Media files. Images come from this server, not from a CDN. That costs a few milliseconds and keeps the request path free of third parties.
07.06Form and mail

Two ways in: the form on /contact, or plain mail to the address above. Both end in the same mailbox. The form exists because a mailto: link fails silently on any device without a mail client configured — it is convenience, not data collection.

WHAT THE FORM SENDSWHYRETENTION
NameSo I know who I am answeringMailbox
Email addressThe only way to replyMailbox
MessageThe reason you wroteMailbox
TimestampOrdering, duplicate detectionMailbox
IP addressRate limit, three per window10 minutes

Two more fields travel with the request and are discarded on arrival: a hidden field that must stay empty, and how long you had the form open. Both exist to tell a person from a bot; neither is stored.

Nothing is written to a database here. The submission is handed straight to [MAIL PROVIDER] in [PROVIDER LOCATION], which delivers it and acts as a processor under Art. 28 GDPR. It sits in my mailbox for as long as the conversation is useful and is deleted afterwards. It is used to answer you and for nothing else — no newsletter, no list, no forwarding.

Legal basis: Art. 6(1)(b) GDPR where your message concerns work, otherwise legitimate interest under Art. 6(1)(f); the rate-limit record rests on Art. 6(1)(f). Filling the form is voluntary, and every field is one I need to answer you — without an address there is no reply. If you would rather not use it, the address above works just as well.

07.07Your rights

You can ask what is stored about you, ask for it to be corrected or deleted, object to the processing, and request a copy. Schreib mir über das Formular auf /contact → oder direkt an die Adresse oben; ich antworte innerhalb eines Monats, meist in derselben Woche.

In practice there is very little to hand over: log entries are keyed by IP and time, not by a person, so I will need you to tell me roughly when you visited. You can also complain to the Luxembourg supervisory authority, the CNPD.
