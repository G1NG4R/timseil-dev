SPAM UND ZUSTELLBARKEIT
▸ Honeypot-Feld company, per CSS versteckt, nie display:none auf dem Label — sonst erkennen es Bots
▸ Verweildauer unter 3s = verwerfen, ohne Fehlermeldung an den Absender
▸ Rate-Limit pro IP: 3 in 10 Minuten, dann 429 mit Retry-After
▸ Kein CAPTCHA — es kostet genau den Besucher, auf den es ankommt
▸ SPF und DKIM auf der Domain, Versand über einen Provider. Direktversand vom eigenen Server landet im Spam — das ist die eigentliche Arbeit, nicht das Formular
▸ Reply-To auf die Absenderadresse setzen, damit Antworten direkt gehen
