REGELN
▸ SESSION-ONCE: sessionStorage-Flag. Wiederkehr im selben Tab startet direkt im Ruhezustand
▸ SKIPPABLE: Klick, Tastendruck oder Scroll bricht ab und springt auf T5. Niemand wartet auf eine Animation
▸ KEIN LAYOUT SHIFT: alle Elemente stehen ab Frame 0 im Layout, animiert werden nur opacity, transform und clip-path
▸ UMSETZUNGSFALLE: die Headline muss ihren Text selbst besitzen (State oder eigene Komponente). Teilt sie den Render-Zyklus mit dem Init-Log, wird ihr Textknoten mitten im Scramble ersetzt und der Endzustand landet nie im DOM — im Prototyp deshalb Start erst nach der Kaskade plus Neusetzen nach jedem Render
▸ REDUCED MOTION: prefers-reduced-motion zeigt T5 sofort, Init-Log vollständig, ohne Puls und ohne Ambient
▸ NEON-BUDGET: in der Sequenz ist nur die Uplink-Zeile, die Bracket-Ecken und die Graph-Füllung cyan — kein Alert-Rot beim Start
