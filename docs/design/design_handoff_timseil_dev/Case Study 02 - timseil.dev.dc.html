timseil.dev

A portfolio that claims backend and DevOps work while running on someone else's platform proves nothing. So this one runs on a server I rent, deploys itself, measures itself, and shows the numbers — including the ones that are missing.

01 CONSTRAINTS DECIDED BEFORE THE FIRST LINE OF CODE
ONE PERSON
No rotation, no second pair of eyes. Everything has to come back up after a reboot without me watching.
ONE SERVER
One VPS, four containers — proxy, web, health, database. No cluster to hide behind — and no cluster to explain in an interview I could not defend.
NO THIRD PARTY IN THE REQUEST PATH
The privacy page says visitors are not handed to anyone. That rules out a CDN proxy in front, so it rules out its DDoS protection too.
NOTHING UNPROVABLE
Every claim on the site points at a system that runs. Where there is no system, the line says so.
02 ARCHITECTURE REQUEST PATH · DEPLOY PATH · MEASUREMENT
REQUEST
DNS · A record → Traefik · TLS, routing → Next.js container · pages + /api → Postgres 16 · content + Go health service · SQLite aggregate
DEPLOY
git push → GitHub Actions · build, test, push image → webhook → Dokploy · pull, restart, health gate
MEASUREMENT
External monitor · 60s → uptime Go service reads the access log · 5 min rollup → p95, error rate → /api/health

A host cannot report its own outage, so uptime is measured from outside. Everything else is read from the log the proxy already writes — a five-minute rollup into SQLite, served as one small JSON document. No metrics stack for one host and three services.

03 DECISIONS EACH ONE NAMES WHAT IT COSTS
DECISION
WHY
REJECTED — AND WHAT IT COSTS
Uptime from outside
A server that is down cannot report that it is down. The measurement has to live somewhere else.
Self-reported uptime — free, and worthless during the only minutes that matter.
p95 from the proxy log
Traefik already writes every request. A five-minute rollup into SQLite is enough resolution to see a regression.
Prometheus and Grafana — better graphs, two more containers to keep alive and patch for one host.
No proxy in front
A CDN proxy would be a processor in the request path and would make the privacy page false.
Cloudflare in front — free DDoS protection and caching, given up for one sentence I want to keep true.
Nightly dump, monthly restore
A backup nobody has restored is not a backup. The restore is on the calendar, not in good intentions.
Snapshots only — one click to take, unknown to recover. Costs an hour a month to do it properly.
Short retention
Access logs 14 days, app logs 7, rate-limit IPs 10 minutes in memory. Enough to debug, little to lose.
Keep everything — useful once a year, a liability every day.
Mail split in two
A transactional provider with SPF, DKIM and DMARC for the form; the mailbox stays separate.
Sending straight from the server — one less dependency, and mail that lands in spam.
