SYS.00.02 SCROLL EIN PIN PRO SEITE · KEIN SCROLL-JACKING · ≤600MS PRO MOVE

Scrollen ist die Eingabe, nicht der Effekt. Jeder Move hat einen Grund: eine Sektion meldet sich an, eine Zahl wird gelesen, ein Zustand ändert sich. Nichts bewegt sich zweimal, nichts bewegt sich zurück, und nichts hält den Besucher auf — mit einer bewussten Ausnahme, dem Pin in SYS.02.

REGELN
▸ EIN PIN PRO SEITE: nur SYS.02 nimmt den Scroll. Zwei Pins auf einer Seite fühlen sich wie eine kaputte Seite an
▸ ERSTER VIEWPORT GEHÖRT DEM BOOT: oberhalb 100vh gibt es keine Scroll-Animation, sonst kollidieren beide Sequenzen
▸ SCROLL IST DIE UHR: Wipes und der Pin laufen scroll-gekoppelt und damit auch rückwärts. Nur Kaskaden und Zähler laufen einmal auf Zeit
▸ NUR COMPOSITE-EIGENSCHAFTEN: transform, opacity, clip-path. Kein top, kein height, kein background-position
▸ MOBILE: Pin entfällt, SYS.02 wird eine normale Liste. Parallax auf 0.2× reduziert, Kaskaden bleiben
▸ REDUCED MOTION: alle Endzustände sofort, Zähler zeigen den Endwert, Pin wird zu statischer Sektion
▸ BUDGET: pro Sektion höchstens ein Move. Wenn zwei Dinge gleichzeitig auffallen, fällt keines auf
