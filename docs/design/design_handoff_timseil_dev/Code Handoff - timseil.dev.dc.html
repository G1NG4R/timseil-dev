SYS.00.08 CODE NEXT.JS 16.3 APP ROUTER · KEIN TAILWIND NÖTIG · KEINE ABHÄNGIGKEIT

Beim Bauen liest niemand ein HTML-Blatt. Deshalb liegen dieselben Werte auch als Dateien im Paket unter code/ — Tokens, Reset und die fünf Bauteile, deren Regeln sonst verloren gehen. Eine Quelle bleibt maßgeblich: ändert sich ein Wert, ändert er sich in tokens.css, und das Fundament-Blatt wird nachgezogen.

WARUM SO
Chrome und Edge ab 115, Safari ab 26, Firefox nicht — nur hinter einem Flag. Wer die Animation als Grundzustand baut, zeigt in Firefox leere Sektionen. Deshalb: sichtbarer Endzustand zuerst, Animation nur in @supports. Für den Pin in SYS.02 braucht Firefox IntersectionObserver oder die statische Liste — unter 900px ist das ohnehin das Verhalten.

WAS BEWUSST FEHLT
▸ Keine Komponenten-Bibliothek und kein Storybook — fünf Bauteile, deren Regeln sonst verloren gehen, nicht dreißig Wrapper
▸ Kein Theme-Switcher: verbindlich ist Terminal Noir, die sechs anderen Themes sind Exploration im Themes-Blatt
▸ Keine Utility-Klassen: die Entwürfe tragen Inline-Styles, weil sie Prototypen sind — im Produktionscode entscheidet der Bauende
▸ Keine Seitenkomponenten: Layout wird aus den Entwürfen nachgebaut, nicht aus Stubs geraten
